- 时长要求：大约需要上5-7次课，每次课1.5小时

    1. 课程初衷、内容介绍+生产函数介绍
    2. 初阶增长模型：Solow，存在技术进步的solow模型

    5. 贸易中的创新经济学：Idea Diffusion Model（贸易-> 全要素生产率）

### Lecture 2: 生产函数介绍
```text
+-- 生产函数介绍：
|
+-- 从增长-技术创新-全要素生产率增长的辨析开始引入生产函数
|   - 很多时候，在经济学中，我们通常混淆了增长、技术创新和全要素生产率增长的概念（此处可以互动提问）
|   - 从直觉上说，增长是某种经济总量的增加，他的测度是总产出、GDP（Gross Domestic Product）、增加值（Value Added）甚至是灯光亮度
|   - 技术进步/创新直觉上是研发并采用了新的技术，他的测度通常是专利数量或者是专利质量，或者是二者的某种加总
|   - 全要素生产率直觉上是生产的“效率”，它本身就是一个测度的概念，通过生产函数和数据计算出来的
|   - 尤其注意，很多论文，特别是模型的论文，会把全要素生产率和技术进步直接画等号，但它们其实是两个不同的概念，比如全要素生产率是有可能计算出减少的，但是我们很难理解技术退步这件事情
+-- 生产函数的引入
|   - 先通过一个小故事来引入一个只有劳动的生产函数Y_t=L_t(采集果实)和Y_t=K_t * L_t（种植经济）+ Capital Accumulation(K_(t+1)=I_t+(1-\delta)K_t)
|   - 通过在前面乘上一个数A，来引入全要素生产率的概念
|   - Y=F(A,K,L,...)是最一般的形式，如果我们想测度全要素生产率A，有很多种办法，可以假设各种生产函数形式，比如直接线性、exp函数、log函数，甚至我们可不可以不在不假定特定的生产函数的形式的情况下，把生产函数估计出来（非参估计）
|       - 介绍一下非参估计的基本原理
|   - 通过Kaldor事实，来说明为什么我们选择了Cobb-Douglas生产函数
|   - C-D生产函数怎么估计全要素生产率，以及在数学上有什么弊端
|   - 引入更一般化的CES生产函数形式，并推导它在极限情况下可以恢复其他各种生产函数
|   - 当然CES在很多时候也不是终点，在需要某些特定的性质的时候，我们会拓展它，比如Structural Change Model(这个希望我们最后能有时间讲这些)
```

### Lecture 3: 一个简易的增长框架——Solow Model
``` text
+-- 一个起点：Harrod-Domar Model
|   - 介绍哈罗德多马模型的动机
|   - 模型假设（尤其注意模型的暗含假设：给定A_t时，K_t和L_t是完全互补的）
|   - 模型推导和结论：增长率决定和刀锋条件
+-- 最基础的增长框架：Solow Model
|   - 介绍Solow模型的动机
|   - 模型假设：
|       1. C-D生产函数（替代掉了Harrod-Domar模型的K_t和L_t是互补的假设，这其实是模型能够稳定的）
|       2. 在基础版本中，不加入技术进步和人口增长
|       3. 外生储蓄率
|   - 模型推导和结论：
|       1. 增长率决定
|       2. 稳态的稳定性
|       3. 外生储蓄率对增长率的影响
|       4. 黄金率
|
+-- 拓展的Solow Model：加入技术进步和人口增长
|   - 主要介绍拓展后的推导办法：去增速
|   - 模型结论：
|       1. 技术进步和人口增长对增长率的影响
|       2. 总量增长、人均增长、有效人均增长的区别
|
+-- 回到Kaldor事实：对比各个模型对Kaldor事实的符合程度
```

### Lecture 4: 内生增长框架——Romer Model
```text
+-- 从Solow模型留下的问题出发：技术进步能否由经济体系内部产生？
|   - Solow模型已经说明：仅依靠资本积累，由于资本边际报酬递减，人均增长最终会停止；持续的人均增长必须依靠技术进步
|   - 但Solow模型直接给定技术增长率g_A，无法解释谁在创新、为什么创新、创新者如何获得回报，以及政策和市场规模为什么会影响创新
|   - 本节的核心任务不是再次证明“技术推动增长”，而是把技术A_t从外生过程改写为有成本、有收益、由经济主体主动生产的内生变量
|   - 需要区分三个概念：资本积累是复制既有投入，技术采用是使用已有知识，创新是创造新的设计、蓝图或产品种类
|
+-- 典型事实与理论动机
|   - 长期人均产出可以持续增长，单纯的物质资本积累却存在明显的边际报酬递减
|   - 企业和政府持续投入研发，专利、科研人员和新产品数量与生产率增长存在系统性联系；这些事实为模型提供动机，但不等于已经证明研发对增长的因果效应
|   - 一个想法可以被许多企业同时使用而不会被耗尽，因此知识具有非竞争性；但专利、保密和技术壁垒又能使知识在一定程度上具有排他性
|   - 非竞争性意味着复制生产可以保持规模报酬不变，而把知识也作为投入后，经济整体可能具有递增报酬；这使完全竞争不能同时覆盖所有投入成本
|
+-- 前序文献与Romer模型的定位
|   - Arrow的learning by doing：知识随生产和投资附带产生，说明知识外溢可以抵消报酬递减，但没有显式的研发选择
|   - Romer(1986)：把知识积累和外部性放入增长模型，为持续增长提供机制，但创新的产权、价格和研发部门仍不完整
|   - Dixit-Stiglitz垄断竞争框架：让不同品种具有市场势力，为新产品和专利定价提供可解的市场结构
|   - Romer(1990)：把最终品、中间品、研发和家庭决策放进同一一般均衡框架，显式回答研发激励和知识生产问题
|
+-- 先讲清楚知识的经济学属性
|   - 竞争性：一台机器被一家企业使用后，不能同时被另一家企业使用；一个生产公式却可以被多人同时使用
|   - 排他性：知识是否能够通过专利、版权、保密或技术门槛阻止他人使用，决定创新者能否获得私人收益
|   - 模型的关键组合是“非竞争但部分可排他”：非竞争性产生社会收益和规模效应，可排他性产生专利租金和私人研发激励
|   - 隐含限制：蓝图质量同质、专利边界清楚、知识可以被精确计数，现实中的累积创新、专利诉讼和隐性知识被大幅简化
|
+-- Romer(1990)品种扩张模型的市场结构与时序
|   - 家庭拥有劳动和人力资本，进行消费储蓄决策；CRRA偏好给出Euler方程，并把利率与消费增长联系起来
|   - 最终品企业完全竞争，使用劳动、人力资本和一组差异化中间品生产最终产品
|   - 每一份新蓝图对应一种新的中间品；专利持有者独占生产该品种，因此面对向下倾斜的需求曲线并收取加成
|   - 研发部门使用人力资本和已有知识创造新蓝图；人力资本在最终品生产H_Y和研发H_A之间配置，满足H=H_Y+H_A
|   - 一期内的逻辑顺序：家庭配置资源 -> 最终品企业选择中间品 -> 垄断者定价生产 -> 研发部门进入并创造蓝图 -> A_t进入下一期生产可能集合
|
+-- 生产端：为什么增加品种能够提高总产出？
|   - 课堂简化形式可写为Y=H_Y^(1-alpha) * integral_0^A x(i)^alpha di，其中0<alpha<1
|   - 对单个中间品x(i)存在边际报酬递减，但新品种扩大了可用投入集合；A增加时，企业不必只在旧品种上继续堆积投入
|   - 最终品企业的一阶条件给出每个中间品的反需求p(i)=partial Y/partial x(i)
|   - 对称均衡下所有中间品使用量相同，积分项化为A*x^alpha，由此可以直接看出品种数量A如何进入总产出
|   - 需要强调：这里的A首先是“蓝图或中间品种类数”，并不是从数据中直接测得的Solow residual；二者只有在特定聚合条件下才能建立对应
|
+-- 中间品垄断定价：专利为什么能产生研发回报？
|   - 中间品企业购买一份蓝图后永久或在专利期内垄断该品种，选择x(i)或价格p(i)以最大化利润
|   - 常数弹性需求使最优价格等于边际成本乘以固定加成；加成收入形成每期垄断利润pi
|   - 专利价值V等于未来垄断利润的贴现值，满足资产定价条件rV=pi+dot(V)；稳态且利润不变时可简化为V=pi/r
|   - 垄断不是为了描述所有企业都永久垄断，而是模型中把创新的社会价值转化为可交易私人资产的闭合机制
|   - 移除专利或其他排他机制后，知识仍有社会价值，但研发者无法收回成本，竞争性私人研发可能降为零
|
+-- 研发部门、自由进入与内生增长率
|   - 基准知识生产函数写为dot(A)=eta*H_A*A：研发人员越多，新想法到达越快；已有知识越多，后续研究越容易
|   - A同时出现在研发生产函数中，表示研究者可以免费借鉴社会已有知识，这是跨期知识外溢，也是持续增长的关键来源
|   - 自由进入条件把研发成本与蓝图价值相等：研发人力的一单位工资成本 = 该单位人力创造蓝图的数量 * V
|   - 最终品部门和研发部门争夺人力资本，工资相等条件决定H_Y与H_A的配置，而不是外生给定研发占比
|   - 平衡增长路径上g_A=dot(A)/A=eta*H_A；再结合垄断利润、资产定价、家庭Euler方程和人力资本约束，闭合利率、消费增长和研发投入
|   - 推导顺序应保持为：中间品需求 -> 垄断价格与利润 -> 专利价值 -> 研发自由进入 -> 人力资本市场出清 -> 平衡增长率
|
+-- 核心结论及比较静态
|   - 技术进步不再凭空给定，而是由研发生产率、市场规模、专利价值、利率和研发人力共同决定
|   - 更高的研发效率eta、更丰富的人力资本或更高的创新收益通常提高研发投入和增长率；更高的贴现率会降低长期专利价值和研发激励
|   - 市场规模扩大提高每个品种的潜在利润，在基准版本中可能永久提高增长率，这就是Romer模型的强规模效应
|   - 储蓄和研发政策不只改变稳态收入水平，还可能改变长期增长率，因此与Solow模型中“储蓄率只影响水平”的结论不同
|
+-- 市场均衡与社会最优为什么不同？
|   - 知识溢出：研发者没有获得新知识对未来研究者的全部帮助，导致私人研发回报低于社会回报
|   - 消费者剩余：创新者只获得垄断利润，不能获得新品种为最终品生产者带来的全部剩余
|   - 垄断扭曲：专利加成使中间品使用量低于边际成本定价下的水平，因此专利同时提供创新激励并造成静态效率损失
|   - 基准模型通常支持研发补贴，但最优政策必须同时考虑知识外溢、垄断加成和财政成本，不能简单推出“专利越强越好”
|
+-- 关键设定的反事实检验与模型局限
|   - 若移除知识的非竞争性和知识外溢，研发同样受到递减报酬约束，模型会重新接近Solow式的水平效应
|   - 若令H_A=0或eta=0，则dot(A)=0，长期人均增长失去内生来源
|   - 若新产品替代旧产品而不是与旧产品并存，模型就需要进入下一讲的质量阶梯和创造性破坏机制
|   - 强规模效应受到Jones(1995)等文献质疑；把知识生产函数改为dot(A)=eta*H_A*A^phi且phi<1后，长期增长更多由研发人口增长决定，这属于半内生增长版本
|   - 基准模型弱化了研发不确定性、企业异质性、创新质量差异和旧技术退出，因此适合解释“新品种如何产生增长”，不适合直接解释企业更替
|
+-- 回到增长理论主线
|   - 与Solow对比：Solow给定g_A，Romer解释A如何由有目的的研发活动产生；前者强调收敛，后者强调知识、市场结构和政策
|   - 与Kaldor事实对比：模型能够产生稳定的人均增长和资本产出比，但强规模效应是否符合跨国和时间序列事实需要单独检验
|   - 为下一讲留下的问题：如果创新不是增加并存品种，而是新技术淘汰旧技术，垄断价值、企业进入退出和福利结论会发生什么变化？
```

### Lecture 5: 内生增长框架——Quality Ladder Model
```text
+-- 从Romer品种扩张到质量阶梯
|   - Romer模型中的新蓝图增加一种可以长期并存的中间品，增长来自品种边际的扩张
|   - 现实中的很多创新表现为同一用途产品的升级：新芯片替代旧芯片、新药替代旧疗法、新工艺使旧设备和旧专利贬值
|   - 质量阶梯模型把创新写成“更高质量取代现有质量”，从而引入企业更替、专利竞赛和Schumpeter意义上的创造性破坏
|   - 本节核心问题：创新者的收益为什么来自夺走现任者市场？这种私人收益与社会收益为什么可能不一致？
|
+-- 前序文献与两个经典版本
|   - Schumpeter：资本主义增长来自不断创造新技术并摧毁旧生产组织，但没有给出可计算的一般均衡模型
|   - 专利竞赛文献：企业投入研发以争夺一个离散创新奖品，为随机创新和先到者获胜提供分析工具
|   - Romer(1990)：建立研发、专利和垄断的一般均衡框架，但新品种通常不会使旧品种退出
|   - Grossman-Helpman(1991)：在连续多个产品线上设置质量阶梯，适合研究产品升级、国际贸易和跨行业创新
|   - Aghion-Howitt(1992)：用Poisson创新过程刻画全经济质量跃迁，把增长、研发劳动配置和创造性破坏放入一般均衡
|   - 两个版本应分别讲授：Grossman-Helpman强调多产品线的逐线升级；Aghion-Howitt基准模型强调经济整体的一次次随机跃迁，不能直接混写公式
|
+-- 典型事实和模型希望解释的现象
|   - 长期生产率增长伴随企业进入、退出、市场份额重配和产品更新，说明创新不仅增加知识存量，也会使旧资产贬值
|   - 研发结果具有高度不确定性，投入增加通常提高成功概率，却不能保证某一时点必然成功
|   - 创新领先者往往获得暂时的高利润，但领先地位会被下一次创新终结；利润持续时间与后续创新速度相关
|   - 这些事实是质量阶梯的理论动机；Poisson到达、统一质量步长和赢家通吃式专利则是为了可解性而作的简化
|
+-- 基准质量阶梯的技术和市场结构
|   - 当前最好技术位于质量阶梯的第j级，质量为q_j=lambda_q^j*q_0，其中lambda_q>1是每次创新的质量提升幅度
|   - 成功创新使质量从q_j跳到q_(j+1)=lambda_q*q_j，上一代技术失去市场或只能以竞争性价格销售
|   - 制造部门使用当前最先进中间品和生产劳动制造最终品；研发部门使用研发劳动z寻找下一代技术
|   - 研发成功服从Poisson过程，到达率写为mu*z；在很短时间dt内，成功概率约为mu*z*dt
|   - 成功者获得下一代专利并成为新的垄断者，现任者的价值在下一次创新到达时被摧毁
|   - 劳动力在生产和研发之间配置，例如y+z=L；更多研发提高未来增长率，却减少当期用于生产的劳动和消费
|
+-- 为什么使用Poisson过程？
|   - 它把“研发投入提高成功概率”和“创新时点不可预测”同时写入模型，并允许用连续时间HJB处理资产价值
|   - 无记忆性意味着过去失败多久不影响下一瞬间的成功概率，这一假设大幅简化动态规划，但忽略项目成熟度和累积试验过程
|   - 多个独立研发者同时竞争时，总创新到达率可以加总；自由进入决定有多少资源投入专利竞赛
|
+-- 产品市场定价、利润与创新步长
|   - 新一代产品质量更高，领先者可以凭借质量优势定价；价格上限通常受到上一代产品竞争或最终品企业替代选择的约束
|   - 若质量差距有限，领先者常采用限制性定价，使使用旧技术的单位质量成本恰好没有吸引力
|   - 创新步长lambda_q越大，领先者可获得的质量溢价和垄断利润通常越高，成功创新的私人奖品随之增加
|   - 具体价格和利润公式依赖最终品技术、旧技术是否免费可用以及专利保护范围，讲义中必须先固定版本再推导，不能把不同论文的加成公式拼接
|
+-- 现任垄断者的价值：创造性破坏如何进入HJB？
|   - 令V_j为拥有第j级技术的垄断价值，pi_j为当期利润，tau为下一次创新的到达率
|   - 最简现任者HJB可写为rV_j=pi_j+dot(V_j)-tau*V_j；最后一项是专利被下一代技术淘汰造成的预期资本损失
|   - 若下一次创新到来时现任者仍保留残值，应把跳跃后的价值差写为tau*(V_after-V_j)，而不是机械地令价值归零
|   - 解得的V随当期利润上升而上升，随利率和创造性破坏率上升而下降：创新越快，当前垄断租金的预期寿命越短
|
+-- 潜在创新者的研发条件
|   - 研发企业支付工资购买研发劳动，成功后获得新一代专利价值V_(j+1)，失败时没有产出
|   - 自由进入条件的一般形式为“单位时间研发成本 = 创新到达率的边际增量 * 成功后的价值”
|   - 在简单线性到达率下可写为w_z=mu*V_(j+1)；若存在研发拥挤、固定成本或在位者优势，条件需要相应修改
|   - 把这一条件与生产部门劳动需求、家庭Euler方程和劳动力市场出清联立，才能决定均衡研发劳动z，而不能直接假定研发比例
|
+-- 从随机创新推导长期增长率
|   - 每次成功创新使质量乘以lambda_q，因此对数质量提高ln(lambda_q)
|   - 单位时间创新次数的期望为mu*z，所以对数质量的期望增长率为g_q=mu*z*ln(lambda_q)
|   - 若最终产出与前沿质量成比例，长期产出增长率也与mu*z*ln(lambda_q)成比例；具体系数取决于生产函数中质量的指数
|   - 质量水平的期望增长率mu*z*(lambda_q-1)与对数质量增长率mu*z*ln(lambda_q)并不相同，只有在lambda_q接近1时二者才近似相等
|   - 推导顺序应保持为：产品市场利润 -> 现任者价值 -> 研发自由进入 -> 劳动力配置 -> 创新到达率 -> 期望增长率
|
+-- 创造性破坏带来的外部性与福利判断
|   - 知识溢出效应：新研究建立在旧知识之上，创新者没有获得其对未来研究的全部社会贡献，可能导致研发不足
|   - 商业窃取效应：进入者把现任者利润转移给自己，这部分私人奖品只是租金重新分配而非等额社会收益，可能导致研发过度
|   - 消费者剩余效应：创新者不能获得质量提升给消费者和下游企业带来的全部收益，可能导致研发不足
|   - 跨期替代效应：今天创新会改变下一代创新的基准、收益和到达时间，不同模型设定下方向可能不同
|   - 因而自由市场研发可能过少，也可能过多；质量阶梯模型不能仅凭“知识有外部性”就推出单向研发补贴结论
|
+-- 比较静态与政策讨论
|   - 更高的研发效率mu和更大的质量步长lambda_q通常提高潜在增长收益，但也可能缩短旧资产寿命并加剧资源从生产向研发转移
|   - 更高利率或更强时间贴现降低未来专利价值，从而减少研发进入
|   - 更强专利保护提高创新奖品，但也可能提高加成并延缓后续创新；最优专利政策需要权衡动态激励和静态损失
|   - 产品市场竞争既可能压低创新租金，也可能迫使接近技术前沿的企业通过创新逃离竞争；这一非单调关系需要更丰富的多企业版本
|   - 研发补贴、竞争政策、专利期限和基础研究投入针对的是不同扭曲，不能被合并为一个笼统的“鼓励创新”政策参数
|
+-- 关键设定的反事实检验
|   - 若lambda_q趋近于1，单次创新几乎不改善质量，增长率趋近于零；若mu或z趋近于零，创新到达和长期增长也趋近于零
|   - 若新技术不淘汰旧技术，HJB中的破坏项消失，模型更接近Romer式品种扩张，现任垄断价值和政策含义都会改变
|   - 若创新结果完全确定，则Poisson风险和专利竞赛消失，需要改用确定性研发积累模型
|   - 若允许在位企业自己创新、多个企业并列在前沿或创新步长内生，就会得到更丰富的创新惯性、逃离竞争和企业动态
|
+-- 模型局限及与前后课程的衔接
|   - 统一质量步长、统一研发效率和瞬时淘汰难以描述渐进改良、多用途技术、专利组合和组织资本
|   - 基准模型常有类似Romer模型的规模效应；必须借助研发拥挤、知识难度上升或半内生增长设定与长期数据相协调
|   - 与Romer对比：Romer研究新种类如何扩大投入集合，质量阶梯研究新一代如何取代旧一代；两者都通过暂时市场势力为研发融资
|   - 与Solow对比：技术增长率现在由创新概率、创新步长和研发资源配置决定，而不再是外生参数
|   - 与后续贸易课程衔接：开放经济会改变市场规模、竞争强度、利润持续时间和可借鉴的知识来源，因此贸易既可能影响创新，也可能传播创新成果
|   - 最后回到Kaldor事实：模型可以生成持续增长，但企业更替、研发波动和结构变化意味着平衡增长路径只是长期近似，而不是每一期数据都应严格满足的事实
```
